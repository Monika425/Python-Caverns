# Activity cave backgrounds

The ten generated backgrounds are mapped in expedition order:

1. Bioluminescent Crystal Cave Tunnel — darkest starting tunnel
2. Mystical Blue Crystal Cave Tunnel
3. Mystic Crystal Cavern Ruins
4. Glowing Crystal Cavern Passage
5. Mystical Crystal-Lit Cave Passage
6. Enchanted Crystal Cavern Passage
7. Enchanted Crystal Cavern Passage (1)
8. Mossy Crystal Cavern Gateway
9. Crystal-Lit Cave Opening to a Misty Valley
10. Crystal Cave Waterfall Valley — outside the cave

The journey loads `chamber-01.jpg` through `chamber-10.jpg` as the user enters each activity. Background changes fade in smoothly while the existing hologram transitions and movement controls remain in place.
